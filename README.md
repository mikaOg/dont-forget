# EthioTrend Pro 🚀

Real social media analytics platform with FREE APIs. Get real stats from YouTube, TikTok, news, and more.

## ✨ Features

- 📊 **Real Trends** - YouTube trending, Google News, Twitter trends
- 🤖 **AI Content Analyzer** - Viral score, sentiment analysis, pro tips
- 📱 **My Stats** - Real YouTube & TikTok statistics
- 🏷️ **Hashtag Generator** - Trending hashtags for your niche
- 📅 **Best Time to Post** - Optimized posting schedule for Ethiopia
- 📈 **Growth Predictor** - 30-day follower projection
- 💬 **Engagement Analyzer** - Real engagement metrics
- 🏁 **Competitor Watch** - Compare with top creators
- 💡 **Content Ideas** - AI-powered content suggestions
- 👥 **Audience Insights** - Demographic analysis
- ⭐ **Performance Score** - Overall account health
- 👤 **User Profile** - Premium subscription with Telebirr/CBE

## 🛠️ Tech Stack

- **Backend**: Node.js, Vercel Serverless Functions
- **APIs**: YouTube Data API v3, Groq AI, Google News RSS
- **Database**: Neon PostgreSQL
- **Cache**: Upstash Redis
- **Payments**: Telebirr, CBE
- **Deployment**: Vercel

## 📋 Prerequisites

- Node.js 18+
- Vercel CLI
- Free API keys (see below)
